Scarica per Windows — v1.1.0Prova portable nel browser

Gratis — Windows 10/11 64-bit — ~15MB MSI

Security Guard

  • Hash SHA-256 + VirusTotal: reputazione online senza AV da 500MB
  • Miner nascosti: CPU>30% o GPU>50% a riposo
  • Publisher Check: verde firmato, giallo/rosso non firmato o nomi casuali
  • Rete attiva + Startup HKCU/HKLM Run — disabilita in un clic

Trovato virus? Fai cosi:

  1. Isola il processo
  2. Controlla firma e percorso (Temp = sospetto)
  3. Verifica SHA-256 su virustotal.com
  4. Disabilita Startup, riavvia, cancella
  5. Defender offline + cambia password
