Disabilita la voce Startup, riavvia, Defender offline, cambia password.

FAQ

Domande frequenti

È davvero un'app Windows o solo una pagina?

È un'app Windows nativa (.hta): gira con mshta già incluso in Windows, legge i processi reali via WMI, termina, legge il registro Startup e calcola gli hash. Niente browser, niente terminale.

Posso rompere Windows chiudendo un processo?

No: Safety Tag blocca explorer, csrss, dwm, lsass, wininit e servizi critici con popup dedicato.

Cosa serve per VirusTotal?

Una key gratuita da virustotal.com: l'app calcola lo SHA-256 in locale e apre il report. Mai visto + non firmato = sospetto.

Quali dati raccoglie?

Zero telemetria. Tutto resta sul tuo PC: WMI, registro e hash sono letti in locale.
